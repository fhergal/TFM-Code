# Comandos disponibles

El usuario los escribirá literalmente en el prompt:

- `/tfm-section`: redacta o reescribe un apartado concreto del TFM siguiendo tono académico, citando conceptos clave, manteniendo o mejorando la estructura actual.
- `/tfm-review`: revisa un texto del TFM, señalando incoherencias, mejoras de estructura y propuestas de reescritura más claras.
- `/spec`: genera o refina especificaciones técnicas (SpecDD) para componentes del sistema (parser, RAG, agente de bastanteo), con entradas, salidas y contratos.
- `/lti-tests`: genera o mejora tests unitarios para el proyecto LTI (inserción de candidatos, casos borde, manejo de errores), con foco en claridad y mantenibilidad.
- `/refactor-code`: refactoriza código existente, aplicando buenas prácticas, nombres claros y separación de responsabilidades.
- `/resume`: sintetiza en pocas líneas el estado actual, decisiones tomadas y próximos pasos, para actualizar el log de progreso.

## Ejemplos de uso

- "/tfm-section redacta el subapartado "Origen de los datos" en 350-450 palabras, integrando datos públicos + sintéticos, para mi TFM de bastanteo administrativo."
- "/lti-tests propon 5 casos de test unitario para la inserción de nuevos candidatos en el LTI, cubriendo casos borde habituales."

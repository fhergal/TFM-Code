# TFM-Code

Repositorio de código y contexto de trabajo para el TFM (arquitecturas agénticas E2E para bastanteo administrativo en AA.PP.).

## Estructura

- `CLAUDE.md` — contexto persistente que Claude Code carga automáticamente en cada sesión (importa los archivos de `claude-framework/`).
- `claude-framework/`
  - `PERSONA.md` — rol y objetivos del asistente para este proyecto.
  - `RULES.md` — reglas de estilo y de ahorro de tokens.
  - `COMMANDS.md` — comandos cortos (`/tfm-section`, `/tfm-review`, `/spec`, `/lti-tests`, `/refactor-code`, `/resume`) y ejemplos de uso.
